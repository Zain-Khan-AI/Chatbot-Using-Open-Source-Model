# ⚡ Groq Open-Source AI Assistant

A fast and clean **AI Assistant** built with **Python**, **Streamlit**, and the **Groq API**. It lets you chat with open-source LLMs in real time through a dark-mode interface.

## ✨ Features
- **Fast Responses:** Powered by Groq API for low-latency replies.
- **Model Selection:** Switch easily between `openai/gpt-oss-120b`, `openai/gpt-oss-20b`, and `qwen/qwen3.8-27b`.
- **Chat Memory:** Keeps your conversation history with a one-click clear button.
- **Custom Dark UI:** Clean glassmorphism styling built with custom CSS.

## 🚀 How to Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd Groq-OpenSource-AI-Assistant
   ```

2. **Install required libraries:**
   ```bash
   pip install streamlit groq
   ```

3. **Run the app:**
   ```bash
   streamlit run app.py
   ```

4. **Use the app:**  
   Get a free API key from [Groq Console](https://groq.com), paste it in the sidebar, and start chatting.
